# 🚀 STO iPhone Catalão - Website Premium

Website premium e responsivo para a loja de iPhones e produtos Apple em Catalão, Goiás.

## 📁 Estrutura do Projeto

```
sto-iphone-vscode/
├── public/
│   └── index.html           # Página principal
├── src/
│   ├── css/
│   │   └── styles.css       # Estilos CSS completo
│   ├── js/
│   │   └── scripts.js       # JavaScript
│   └── assets/
│       └── images/          # Imagens (coloque logo.png aqui)
├── .vscode/

│   ├── extensions.json      # Extensões recomendadas

└── README.md                # Este arquivo
```

## 🚀 Como Usar

### 1️⃣ Abrir no VS Code

```bash
code sto-iphone-vscode
```

### 2️⃣ Instalar Extensões (Automático)

Ao abrir, VS Code oferecerá para instalar as extensões recomendadas:
- ✅ Prettier (formatação)
- ✅ Live Server (servidor local)
- ✅ Tailwind CSS (autocompletar)

### 3️⃣ Rodar o Projeto

**Opção A - Live Server (Recomendado)**
1. Clique direito em `public/index.html`
2. Selecione "Open with Live Server"
3. Pronto! Abrirá em http://localhost:5500

**Opção B - Terminal**
```bash
npm install
npm start
```

**Opção C - Python**
```bash
cd public
python -m http.server 8000
# Acesse: http://localhost:8000
```

## 📱 Logo da Marca

Para que a logo apareça:
1. Coloque seu arquivo em `src/assets/images/logo.png`
2. Recomendação: 200x200px ou maior
3. Formato: PNG com fundo transparente
